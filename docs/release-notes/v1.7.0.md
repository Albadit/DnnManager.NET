# DNN Manager 1.7.0

**Works and looks like VS Code.** DNN Manager now updates itself, opens where you left it and can be used entirely from the keyboard, with a command palette, VS Code's Dark Modern and Light Modern colours and a layout you can arrange.

## Highlights

### Updates itself
- When GitHub has a newer release, a blue **Update** button appears in the title bar. It downloads the release, checks its size, SHA-256 and version, installs it and opens the new version on the same page, project and Details tab.
- If anything fails before DNN Manager closes, the current version keeps running. A failed install starts the old version again and says why.
- It checks a few seconds after start, every 6 hours, and on **Settings → About**, which follows the update as it happens.

### Opens where you left it
- After a close, a restart, an update or a crash: the window's place and size, the page, the Projects table (search, sorting, expanded and selected rows, scroll position), the open Details and their tab, and the bottom panel.
- What you typed on **New project** and **Host project**, and unsaved changes on **Settings**, come back too. Passwords and terminals are never kept.
- It is saved in `Documents\DnnManager\state`. **Reset to factory defaults** forgets it.

### Everything from the keyboard
- **Ctrl+Shift+P** opens the command palette with every command that makes sense now, and **Ctrl+P** goes to a project. The search in the middle of the title bar opens it too.
- Shortcuts for the common actions: **F5** / **Shift+F5** / **Ctrl+Shift+R** start, stop and restart the selected project, **Ctrl+,** opens Settings, **Ctrl+J** the panel, **Ctrl+`** the terminal, **Ctrl+B** the sidebar, **Ctrl+1-3** the pages, **Ctrl+W** closes the view.
- **Settings → Keyboard shortcuts** lists every command, to search, change and reset - conflicts are flagged. Every button's tooltip names its shortcut as it is set now.
- In the Projects table, a click puts the keyboard there: the arrows move between rows, **→** / **←** show and hide a row's details, **Enter** opens it, **Del** removes it.
- In the terminal list, **Del** closes a terminal, **F2** renames it, and you can drag terminals (or use **Alt+↑** / **Alt+↓**) to reorder them.

### VS Code's look
- **Dark** and **Light** use the colours of VS Code's Dark Modern and Light Modern. Pick them, or **System**, from the gear's **Themes**.
- The gear at the bottom of the sidebar opens VS Code's *Manage* menu: **Command Palette…**, **Settings**, **Keyboard Shortcuts**, **Themes**, **Customize Layout…**, **Troubleshoot** and **Check for Updates…**.
- **Settings** and **Troubleshoot** open over the page, which is dimmed behind them. **Esc**, **Ctrl+W** or a click beside them closes them.
- The running operation is a toast in the bottom-right corner, with **Cancel** and a progress bar. An operation that asks first (such as **Remove…**) only shows once you say yes.
- Rounded sidebar entries, panel tabs and Projects table, lower search fields, and a tooltip on every button.

### Arrange the window
- **Customize Layout…** (title bar, gear menu or palette): show or hide the sidebar, panel and status bar; put the sidebar left or right; let the panel span the whole width; open the command palette at the top or in the centre; choose a **Compact** density.
- Each choice applies and is saved at once, in `layout` in `settings.json`.
- The window now shrinks to 400 × 270 pixels. The panel gets lower in a short window and the status bar stays visible.

## Other changes
- Keep warm for every checked project at once, from the flame in the bulk actions above the Projects table.
- New project, Host project and a project's Details are centred in the window.
- The log file in `Documents\DnnManager\logs` is one line per message (`18:21:16 Database seeded.`), without the operation and stage headings.
- The Output tab keeps its newest line in view, with room under it, while you are at the end.
- Closing DNN Manager with unsaved settings no longer asks - they come back next time. It still asks about a changed password.
- Saving settings no longer shows a toast.
- Fixed: answering **No** to a question such as **Remove…** logged *Aborted by user* as an error.
- Fixed: a maximized window lost a few pixels at the screen edges.

## Upgrading
Install over 1.6.x as usual. Your settings keep their format; the new `layout` section is added with its defaults.
- The versions were renumbered: 2.0.0-2.5.0 are now 1.1.0-1.6.0. If your DNN Manager still says 2.x, install this release over it by hand once - it counts itself newer than any 1.x and won't offer the update.
- The theme is no longer on **Settings → General**. Choose it from the gear's **Themes**.
- Troubleshoot is in the gear's menu, and the projects folder is shown in **Settings → Projects** instead of the sidebar.
- Anything that reads the log file: it no longer has `#` / `##` headings, and there is one space after the time.

## Tested
- All 112 fast automated tests pass, up from 70. New ones cover the update (download checks and the helper), the saved workspace, keyboard shortcuts and the command palette, the layout settings, and search fields.
