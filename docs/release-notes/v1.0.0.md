# DNN Manager 1.0.0

**DNN sites from a terminal menu.** The first release: a console app with an arrow-key menu that sets up, clones and removes local DNN sites on IIS, with their databases in a shared SQL Server container in Docker.

## Highlights

### A DNN site in one go
- **Setup a new DNN project** checks the prerequisites, creates the project folder, downloads and extracts the DNN release you pick from GitHub, creates the IIS website, adds a database to the shared SQL Server container, then starts the site and checks it.
- If the SQL Server container already runs, it is reused and only gets a new database for the project.
- **Remove a DNN project** removes its IIS site, its database and its folder.

### Clone, back up and restore
- **Clone a DNN project** copies a site from a local folder or an FTP server into a new project with its own hostname (`<name>.<HostnameSuffix>`), IIS site and database. The source database is backed up and restored, the database user is remapped, the portal alias is rewritten and `web.config` gets the new connection.
- **Database → Backup database** and **Overwrite database**.
- FTP connections can be saved per user (**Edit saved connections**), with the password protected by Windows DPAPI.

### Built for the keyboard
- `↑` / `↓` to move, `1`–`9` to quick-select, `Enter` to confirm, `Esc` to go back, `Y` / `N` in confirmations.
- **Check prerequisites** checks Docker and the IIS Windows features; **Show all projects info** lists every project.

## Other changes
- Settings can be changed in `appsettings.json` next to the program, without recompiling; `DNNMGR_` environment variables override them.
- VS Code tasks to build, clean and publish.

## Upgrading
The first release - nothing to upgrade. It needs Windows 10/11 or Windows Server with IIS, Docker Desktop (Linux containers) and an account that can run as Administrator; DNN Manager asks to elevate when it starts.
