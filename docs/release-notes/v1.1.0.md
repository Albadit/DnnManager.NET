# DNN Manager 1.1.0

**Move projects around and fix your setup from one page.** Export a project as a `.zip` + `.bacpac`, keep dated backups, check and set up Docker, SQL Server and IIS from the new Environment page, and do more straight from the Projects table - all in a faster, fully themed app.

## Highlights

### Import, export and backups
- **Export** a project from its right-click menu - site and database, only the site files, or only the database. Backups go to `<project>\01_backup\<project>_<date_time>\`, or anywhere with **Export to another folder…**.
- **New project → An existing site** creates a project from a site `.zip` and its `.bacpac` - pick one of a project's backups by date, or files from anywhere on your PC.
- The backups folder is protected: IIS won't serve anything in `01_backup`, and exports never include earlier backups.

### New Environment page (replaces Prerequisites)
One place to see what's working and fix what isn't - each part with a **Test** button and a green / red status:
- **Docker Desktop** - install it (via winget) or start it
- **SQL Server container** - set it up or start it (`docker-compose.yml` is generated from your settings)
- **SQL Server connection**
- **IIS Windows features** - enable the missing ones, and **Reset IIS**

### Projects table
- New **SQL** and **IIS** columns: **Live** in green, **Offline** in red.
- Shows each project's **DNN version**.
- **Right-click a project** for:
  - **Details…** - IIS bindings, app pool, database size, portal aliases, the DNN version in the database, web.config settings and more
  - **Open in** Visual Studio, VS Code, Cursor, Windsurf, Rider or Sublime Text (whatever is installed)
  - **Open in SQL Server Management Studio** - signs in to the project's database (or the local server) for you, and reuses an SSMS that's already open
  - **Open folder**, **Copy path**, **Export**, **Remove…**

## Other changes
- **HTTPS redirects are switched off for local sites** (with a reminder to switch them back on before deploying).
- The **activity log** is selectable and copyable.
- **Removing a project** now closes the programs that still have files open in it (after asking) instead of giving up.
- Themed dialogs, the DNN icon, a faster start (precompiled build), and pages that open without waiting.

## Upgrading
Download `DnnManager-1.1.0-x64.zip`, extract it anywhere and run `dnnmgr.exe` - a single self-contained file, no .NET install needed. `appsettings.json` and `docker-compose.yml` are created next to it on first start. It needs Windows 10/11 or Windows Server with IIS, Docker Desktop (it can be installed from the Environment page) or your own SQL Server, and an account that can run as Administrator.
- **Start your SQL container from the Environment page.** DNN Manager no longer starts it on its own. Setting it up rewrites `docker-compose.yml` from your settings; your existing data and sa password are kept.
- **FTP cloning and the Live sites page are gone.** `connections.json` is no longer used and can be deleted. Clone now copies from a local folder and reads the source database from its `web.config`.
- **New backups go to `01_backup`.** Existing `backups` folders are still read, not moved.
- The SQL Server host now defaults to `localhost`; an existing `127.0.0.1` keeps working.
