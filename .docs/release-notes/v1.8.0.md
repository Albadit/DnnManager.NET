# DNN Manager 1.8.0

**Install it as an MSIX package.** Besides Setup and the portable exe, DNN Manager now comes as `DnnManager_1.8.0_x64.msix` - installed, upgraded and removed by Windows itself, without Administrator rights to install.

## Highlights

### An MSIX package
- Download `DnnManager_1.8.0_x64.msix` from this release and open it: Windows' installer shows who published it and installs DNN Manager for you, with its entry in the Start menu.
- Installing needs no Administrator rights. DNN Manager in the package works as it does from Setup: it asks for them (UAC) when it starts, since it manages IIS.
- Your settings are the same ones, in `Documents\DnnManager` - removing or reinstalling the package keeps them.
- Remove it like any app: **Settings → Apps → Installed apps → DNN Manager → Uninstall**.

### Updating a package
- Windows doesn't let a program replace a package's files, so DNN Manager's own update is off in the package: the **Update** button doesn't show, and **Settings → About** says *a package is updated as a package* when GitHub has a newer release.
- Open the next release's `.msix` to update - Windows upgrades it in place and your settings stay.
- **Start DNN Manager when you sign in to your computer** isn't available in the package - start it from the Start menu.

## Other changes
- Setup and the portable exe are unchanged, and keep updating themselves with **Update**.

## Upgrading
Install over 1.7.9 as usual. Your settings keep their format.
- Setup's DNN Manager and the package are separate installations - keep one. To move to the package, uninstall Setup's first (**Settings → Apps → Installed apps**); your settings in `Documents\DnnManager` stay.

## Tested
- The package was built and signed, and passed Windows' package validation.
- All 211 fast automated tests pass, up from 197. New ones cover telling a package apart from Setup's and the portable DNN Manager, and an experimental service for IIS that this release doesn't use yet.
