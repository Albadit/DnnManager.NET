# DNN Manager 1.0.1

**Sites ready for Git.** Setup and Clone drop a DNN-tuned `.gitignore` into each project, all projects share one SQL Server container at a fixed address, and databases move as `.bacpac` files.

## Highlights

### A .gitignore for every DNN site
- **Setup** and **Clone** drop a DNN-tuned `.gitignore` into each project directory, so a freshly installed or cloned site is ready to commit without dragging in build output, NuGet/node packages, or DNN runtime data (`App_Data` DB files, Lucene search index, image/ClientDependency caches, logs, install temp, config backups, and `Portals` user uploads).
- **Never clobbers an existing file** - if the site already ships its own `.gitignore` (e.g. a cloned production copy), it's left untouched.

### One shared SQL Server container
- All projects use one `docker-compose.yml` and one SQL Server container; projects no longer keep their own environment file or Docker folder.
- The container gets a fixed IP address (`ContainerIp` in `appsettings.json`), and Setup, Clone and the database actions connect to it there.

### Databases as BACPAC files
- **Backup database** exports a `.bacpac`; **Overwrite database** restores a `.bak` or a `.bacpac`, and can overwrite a database on another SQL Server, such as Azure SQL, from a `.bacpac`.
- `SqlPackage` is installed as a .NET global tool when it's missing.

## Other changes
- **Remove a DNN project** also deletes the Windows user profile its app pool left in `C:\Users\<project>`, and retries deleting the folder while IIS still holds files.
- **Show all projects info** shows each site's URL as a clickable link.
- Setup and Clone check that IIS is installed first, and report database problems more clearly.
- New VS Code task `zip (DnnManager.zip)`: publishes the single self-contained `win-x64` build and packages `publish/` into `DnnManager.zip` (**Terminal → Run Task… → zip (DnnManager.zip)**).

## Upgrading
Replace `dnnmgr.exe` with the new one. Projects now use the shared `docker-compose.yml` instead of their own Docker folder.
