# DNN Manager 1.8.7

**Pick the host account again.** On a site with more than one host account, **Change host password…** showed an empty **Host account** box. You pick the account from a list again, and the lists in every select mark the right item.

## Highlights

### Choose the host account in Change host password
- On a site with more than one host account, the **Host account** box stayed empty: picking an account from its list didn't show it, so you couldn't tell which account would get the new password.
- The box now shows the account you pick. It starts on the first host account in the site's database.
- It is a plain list now, not a box to type in: it holds every host account in the site's database, and DNN Manager refuses any other name anyway.
- When the site's database has no host account, the dialog says so: *The site's database has no host account to change.*

### Select lists that mark the right item
- The chosen item stays marked as chosen while the list is open. Before, it looked hovered when the list opened and only turned blue once the pointer moved to another item.
- The hover follows the pointer and goes away when the pointer leaves the list. It used to stay on the last item the pointer passed.
- The arrow keys still show which item they are on.
- This applies to every select in DNN Manager, such as **Version** in **New project**, **Upgrade to** in **Upgrade DNN…** and **UI scale** in **Settings**.

## Upgrading
Install over 1.8.6 as usual. Your settings keep their format.

## Tested
- **Change host password** with two host accounts, the dialog drawn off screen with the app's own styles, dark and light: the first account shows when it opens, the one picked shows in the box, and the box can't be typed in.
- The select's list, in the same way: the chosen item stays marked as chosen, an item the pointer has left isn't marked as hovered, and the item the arrow keys are on is.
- All 498 fast automated tests pass, as in 1.8.6.
