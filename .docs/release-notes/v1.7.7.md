# DNN Manager 1.7.7

**Help for anyone new to DNN Manager.** The first start opens a step-by-step guide in plain words, a tour points at each part of the window, and **F1** explains the page you are on.

## Highlights

### Getting started guide
- The very first start opens **Getting started**: eight short steps for someone who has never used DNN Manager, IIS or DNN - what the app does, what to set up first (**Settings → IIS** and **Settings → Database server**), the parts of the window, what the dots in the Projects table mean, and what every button does.
- Each action is marked **Safe**, **Careful** or **Can't be undone**, so you know before you click what stops a website for a moment and what deletes something.
- **Back** and **Next** go through it, the steps on the left jump to one, and **Skip guide** (or **Esc**) leaves it at any time. It is shown once - not again, and not to anyone who already used DNN Manager.
- A new user isn't shown release notes: **What's new** appears only after their first update, when there is something new to tell.

### Tour of the window
- **Take the tour** - on the guide's last step, or in Help - dims the window except one part at a time, ringed in blue, with a card saying what it is for: the pages, the Projects table and the bar above it, the search, Help, the bottom panel, IIS, this PC's figures and the gear.
- **Next** and **Back** (or the arrow keys), **Skip tour** (**Esc**), **Finish** on the last. It opens the bottom panel on the way and closes it again afterwards.

### Help where you need it
- A **?** at the top right of the window: **Help for This Page** (**F1**) explains the page you are on - Projects, a project's details, New project, Host project, Settings or Troubleshoot - and next to it are **Getting Started Guide**, **Take the Tour**, **Keyboard Shortcuts**, **What's New in This Version** and **User Guide on GitHub**.
- **Settings → Help** opens the guide, the tour, What's new and the user guide; the command palette has them under **Help**.
- Pointing at a button now says what it does, not only its name: **Stop** - *turn the website off until you start it again; nothing is deleted*, **Restart IIS** - *every website on this computer is unavailable for a few seconds*. In the Projects table and its bulk actions, a project's details, IIS in the status bar, the panel's tabs, Troubleshoot and the sidebar.

## Other changes
- The downloads are named `DnnManager_Setup-1.7.7-x64.exe` (install or update an installed DNN Manager) and `DnnManager_Portable-1.7.7-x64.exe` (the single exe, nothing to install).
- Fixed: **Documentation** in **Settings → About** opened a page on GitHub that no longer exists.

## Upgrading
Install over 1.7.6 as usual. Your settings keep their format.
- The release also has the same two files under their old names (`DnnManagerSetup-1.7.7-x64.exe`, `DnnManager-1.7.7-x64.exe`), so **Update** in 1.7.6 and older installs this version as before. Downloading by hand, take the new ones.
- **F1** opens Help for the page you are on. If you had given F1 to another command, **Settings → Keyboard shortcuts** marks it as used twice - give one of them another key.

## Tested
- A first start with an empty data folder, in the dark and the light theme: the guide opened by itself, all eight steps, **Take the tour** through every stop, **Settings → Help** and **F1** help. That the guide was seen was kept, and What's new was left out for the new user.
- Both release files were built and came out with their new names.
- All 180 fast automated tests pass, up from 171. The new ones cover when the guide is shown (the first start only, never again, only the new pages after a later version), the help for every page, that every icon the guide uses exists, and that an update is found under the new and the old file names.
